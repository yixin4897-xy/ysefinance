# YSE Finance — proposed YouTube API research privacy notice
**Status: DRAFT ONLY · owner review required · no publication/YouTube approval.**

## Proposed site change

- File: `privacy.html`; new bilingual **Section 9 — Proposed YouTube API Research** plus an accessible table-of-contents link.
- Existing Sections 1–8 for registered tax-agent services, client data, security, rights, website cookies/analytics and contact information remain untouched.
- The notice describes the AESM Social Sentiment Research prototype in the **future/conditional tense**, explicitly says no YouTube comments have been retrieved and no derived-metrics rights have been granted, identifies intended economic-topic analysis, data minimisation, and a future retention/deletion requirement.
- Provides links to [YouTube Terms of Service](https://www.youtube.com/t/terms), [Google Privacy Policy](https://policies.google.com/privacy), [YouTube Developer Policies](https://developers.google.com/youtube/terms/developer-policies), and uses the existing YSE Finance Section 8 privacy contact.
- **No YouTube player, logo, tracking script, comment collector, dashboard, marketing claim, or website service was added.** This Draft is not evidence that any YouTube API client is operational.

## What the site already has

- Existing homepage `index.html` already includes a visible Privacy Policy footer link, so the homepage is **unchanged** in this PR.
- Existing public policy page presents `Last updated: 1 January 2025`. The date has **not** been silently advanced by the Draft. If the owner approves publication, update the visible English/Chinese last-updated date to the **actual effective publication date** in the final merge-ready change.
- No standalone production Terms of Service page was established by this change. YouTube's required Terms documentation must be adopted separately and not misrepresented as already available.
